# TRNT AI & Innovation Lab: Workshop Ideas

Workshop ideas for TRNT Educational Institute, where students aged 8–18 learn AI by building real things.

**Start here:** https://xappert.github.io/TRNT-portfolio-template/

## The workshops

| Workshop | Ages | Students build | Page |
|---|---|---|---|
| 🤖 Build Your Own AI Helper | 8–18 | An AI assistant designed for a real person in their life | [Concept](https://xappert.github.io/TRNT-portfolio-template/concepts/#helper) · [Try the builder](https://xappert.github.io/TRNT-portfolio-template/concepts/ai-helper/) |
| 📷 Invent a Smart Gadget | 8–18 | An invention powered by an image, sound, or pose model they train | [Concept](https://xappert.github.io/TRNT-portfolio-template/concepts/#gadget) |
| 🦾 Build Your Own Jarvis | 13–18 | A personal AI agent with a personality, memory, skills, and a schedule | [Concept](https://xappert.github.io/TRNT-portfolio-template/jarvis/) |
| 🌐 Launch Your Portfolio | 8–18 | A personal website that collects every project above | [Session plan](https://xappert.github.io/TRNT-portfolio-template/workshop/) · [Sample page](https://xappert.github.io/TRNT-portfolio-template/portfolio/) |

## What's in this repository

| Folder | Contents |
|---|---|
| `index.html` | Landing page linking every workshop |
| `concepts/` | AI Helper and Smart Gadget concepts, plus the interactive AI Helper Builder |
| `jarvis/` | Build Your Own Jarvis concept (personal AI agents with Hermes Agent) |
| `workshop/` | The 30-minute portfolio session plan, with age versions, a trial checklist, and a parent note |
| `portfolio/` | The student portfolio template and its [step-by-step student guide](portfolio/README.md) |

Every page is plain HTML with no build step, published with GitHub Pages from the `main` branch.
